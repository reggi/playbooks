# Lean application specifications

**Status: Do not use yet.**

This playbook will define how Lean proofs are used to specify UI behavior, application state, and state transitions.

Topics to specify:

- which behaviors merit formal specification;
- state, event, invariant, and transition representations;
- relationship between proofs and TypeScript implementation;
- naming and repository layout;
- generated artifacts, if any;
- how an agent checks implementation changes against proven properties.
